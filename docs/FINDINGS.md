# FINDINGS — 実機で確かめた結果

T-Beam と GUIDE01 について、実際に動かして確かめたことの記録。失敗も書く。
測った数字には、やり方・回数・条件を付ける。**1 回だけの値は「参考値」**。

最終更新: 2026-11-17

## 2. T-Beam(2026-11-06、1 台目、USB 給電・電池なし)

**電波は出していない**(LoRa は受信と観測だけ。BLE は GUIDE01 との接続)。

| 項目 | 結果 |
|---|---|
| USB | CH9102(`1A86:55D4`)として見える |
| 起動 | USB をつないだだけでは ESP32 が応答せず、**PWR ボタンを押したら起動した** |
| 書き込み | 921600bps は失敗(`Invalid head of packet`)。**460800bps で成功** |
| チップ | ESP32-D0WDQ6-V3(rev v3.1)、フラッシュ 4MB、PSRAM 約 4MB(商品ページの表記は 8MB。差の理由は未確認) |
| I2C | 0x34 だけが応答。**AXP2101**(V1.2 の特徴)。0x3C(OLED)は応答なし |
| 電源 | USB 5070mV、システム 5088mV |
| LoRa のチップ | **SX127x**(バージョンのレジスタ 0x12。SX1276〜79 は区別できない)。SX1262 ではない |
| GPS | NMEA が流れる(30 秒で 150 文、エラー 0)。屋内なので位置は取れていない |
| 周囲の電波(923.2MHz、30 秒、6000 回) | 最小 −125、最大 −110、平均 −120.1dBm。−80dBm 以上は 0 回。屋内・1 回だけの参考値 |
| 基板のボタン(GPIO38) | 押していないとき 1、押すと 0 |
| LED(GPIO4) | LOW で点灯(目視) |
| BLE | 聞くだけのスキャン 10 秒で、周囲の 150 台を検出。BLE の初期化後の空きメモリは約 219KB |

## 3. GUIDE01(2026-11-06、T-Beam 単体から BLE で接続)

公式アプリは使っていない。1 回の通し実行なので参考値。

| 項目 | 結果 |
|---|---|
| 接続 | 成功(電波 −55〜−67dBm、MTU 247) |
| 電池の取得 | 成功(95%) |
| 文字の書き込み | 3 行(85 バイト)、日本語 3 行(103 バイト)、40 桁の数字(58 バイト)、通知(57 バイト)、閉じる(1 バイト)、文字の部品 4 つ(223 バイト)。どれも 1 回の書き込みで成功 |
| 見え方(目視) | 英数字 3 行、通知、日本語 3 行は正常。**40 桁の数字(サイズ 32)は 15 桁くらいで切れた**(折り返さない) |
| 画面の大きさ | 624 × 405、文字を置ける高さ 340(`g01_get_gif_text_consts()`) |
| タッチ | 1 回タップ、2 回タップ、後ろへスワイプ、長押しを受信。前へスワイプは操作していないので未確認 |
| 気づいたこと | **同じタッチの通知が、必ず 3 回続けて届く**(原因は未確認)。文字を出している間の通知はページ番号 0x07、ふだんは 0x01 |
| まだのこと | サイズ別の 1 行の文字数(測る表示は作ってある)、100 回の連続更新、長い時間の接続、Wi-Fi・LoRa と同時に動かしたとき |

## 4. ピンと電源(公式資料で確かめたもの)

出典: LilyGo-LoRa-Series のコミット `1991b1e`(2026-10-12)の `examples/Factory/utilities.h`、`LoRaBoards.cpp`、`docs/en/t_beam/t_beam_hw.md`。
「実機」の列は、手元の T-Beam でも動いたもの。

| 役目 | GPIO | 実機 |
|---|---|---|
| LoRa: SCK / MISO / MOSI / CS | 5 / 19 / 27 / 18 | ○(チップに応答あり) |
| LoRa: RST / DIO0 / DIO1 / DIO2 | 23 / 26 / 33 / 32 | ○(RST、DIO0) |
| GPS: ESP32 が受ける側 / 送る側 | 34 / 12(9600bps) | ○ |
| I2C(電源 IC、OLED): SDA / SCL | 21 / 22 | ○ |
| 電源 IC の割り込み | 35 | — |
| 基板のボタン | 38 | ○ |
| LED | 4(LOW で点灯) | ○ |

| 電源の線(AXP2101) | 供給先 |
|---|---|
| DCDC1 | ESP32 本体(**触らない**) |
| ALDO2(3.3V) | LoRa |
| ALDO3(3.3V) | GPS |
| VBACKUP | GPS の時計 |

- USB 入力の電圧は 3.9〜6V、電池ホルダーは 3.7V のリチウム電池用(`t_beam_hw.md`)。
- 外付けの部品に使うピン(13・14・25・36・39)は、上の表に出てこないことを確かめただけ。**ヘッダのどの穴かは未確認**(`docs/DESIGN.md` §1.2)。

**公式のサンプルをそのまま使ってはいけない点**: 周波数が 920.0MHz(証明書の範囲 920.6〜928.0MHz の外)、出力が 17dBm(上限 12dBm を超える)。使うのは、ピンと電源の設定だけ。

## 5. PC でのテスト

| 項目 | 結果 |
|---|---|
| 共通ロジック(`firmware/core`) | 474 項目、失敗 0(2026-11-17。clang、ASan + UBSan) |

| 送信時間の計算(17 バイト、BW125) | SF7 = 51.5 ミリ秒、SF9 = 164.9 ミリ秒、SF10 = 329.7 ミリ秒(計算値。実測ではない) |

## 6. まだ確かめていないこと

- 注文した T-Beam が「920Mhz MIC」の版か。基板の印字(V1.2)と技適の表示の目視。アンテナの種類
- LoRa の送信(電波法の確認が済むまで行わない。`docs/COMPLIANCE.md`)
- GPS が屋外で位置を取れるか
- Wi-Fi と MQTT、音声の録音、乾電池での動作
- BLE・Wi-Fi・LoRa を同時に動かしたときの安定性とメモリ
